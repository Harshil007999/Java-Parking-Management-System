# Car Parking Management System (Java Swing GUI)

A simple parking lot manager built for the *Programming with JAVA* course (A.D. Patel Institute of Technology).

## Features
- Park a car (first free slot is assigned automatically)
- Remove a car and show the bill (Rs. 20 per hour, minimum 1 hour)
- Colour-coded table of all 10 slots (green = empty, red = occupied)
- Search a car by number
- Running total of money earned

## Run
Requires JDK 8 or newer.

```bash
javac SimpleParkingGUI.java
java SimpleParkingGUI
```
